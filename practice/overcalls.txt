# Your practice hands for Overcalls
#
# When this file has at least one hand, the Overcalls drill shows these hands, in this order,
# instead of random ones. Lines starting with # are ignored.
# After editing, run from the project folder:   python tools/import_practice.py
#
# Each hand starts with a "Hand:" line. The fields:
#   Hand:         the 13 cards, e.g.  S AKJ52  H K74  D Q3  C J82   (10 or T for ten, - for a void)
#                 x for any small card: the importer picks a 2-9 (or the 10) for it
#   Dealer:       who dealt, N, E, S or W                       (optional: helps line up the auction)
#   Auction:      the calls so far, ending with ? for your turn. Bids like 1S or 2NT,
#                 P for pass, X for double, XX for redouble.
#                 The auction starts with the opponents' opening, e.g.  1D ?
#   Answer:       the right call: 1S, 2NT, P, X ...
#   Explanation:  shown with the answer, in English            (optional)
#   הסבר:          shown with the answer, in Hebrew             (optional; with only one of the two,
#                 it's shown in both languages)
#   Note:         shown above the hand, in English               (optional)
#   הערה:          shown above the hand, in Hebrew              (optional)
# A field can continue on the next lines; for example, write four calls per line in an auction.
#
# Examples (remove the # at the start of the lines to use them):
#
Hand: S J8432  H A62  D 73  C 952
Auction: 1D ?
Answer: Pass
Explanation: Not enough HCP or good suit for overcall

Hand: S KQJ84  H A62  D 73  C 952
Auction: 1D ?
Answer: 1S
Explanation: Overcall with 1S with 5 card suit

Hand: S 984  H AQ962  D 73  C K95
Auction: 1S ?
Answer: Pass 
Explanation: Not enough HCP or good suit for overcall at the 2 level

Hand: S 984  H AQJ96  D K3  C K95
Auction: 1S ?
Answer: 2H 
Explanation: Enough HCP and good suit for overcall at the 2 level

Hand: S 9  H AQJ9  D K983  C K952
Auction: 1S ?
Answer: X
Explanation: Takeout double, asking partner to bid his best suit

Hand: S A32  H AQJ932  D K9  C A9
Auction: 1C ?
Answer: X
Explanation: The hand is too strong for simple 1H overcall, so we bid double and then intend to bid hearts over any reponse from partner. This kind of double is called "big double"

Hand: S AQ2  H AQJ9  D K9  C J932
Auction: 1S ?
Answer: 1NT
Explanation: With 15-18 HCP and stopper in opponents suit, bid 1NT

Hand: S 32  H AQJ932  D 109  C J93
Auction: 1C ?
Answer: 2H
Explanation: Weak jump overcall, showing 6 cards and 6-10 HCP

Hand: S 32  H AQJ10932  D 109  C J9
Auction: 1C ?
Answer: 3H
Explanation: Preemptive bid at the 3 level, showing 7 cards and 6-10 HCP

Hand: S 3  H AQJ109832  D 109  C J9
Auction: 1C ?
Answer: 4H
Explanation: Preemptive bid at the 4 level, showing 8 cards
